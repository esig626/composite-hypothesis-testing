# Composite Hypothesis Testing

Private research repository for the composite hypothesis testing project.

The repository is organised so that the manuscript, mathematical result ledger, literature-search records, numerical work, and review notes remain separate but connected.

## Structure

- `manuscript/` — LaTeX manuscript and bibliography.
- `theory/` — theorem ledger, assumptions, proof dependencies, and open questions.
- `literature/` — literature-search ledger and TheoremSearch query records.
- `numerics/` — scripts, notebooks, and generated figures.
- `reviews/` — external feedback and review notes.
- `.codex/` — project-specific Codex configuration.
- `AGENTS.md` — project-level instructions for Codex agents.
